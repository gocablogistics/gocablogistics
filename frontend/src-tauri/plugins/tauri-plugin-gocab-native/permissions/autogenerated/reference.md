## Default Permission

Default permissions for the gocab-native plugin

#### This default permission set includes the following:

- `allow-get-fcm-token`
- `allow-request-notification-permission`
- `allow-start-location-tracking`
- `allow-stop-location-tracking`
- `allow-update-location-token`
